# Turtle Ctrl, FRC Team 12113

Website for Turtle Ctrl, the *FIRST* Robotics Competition team at Hawaiʻi Technology Academy, Kona campus.

Plain HTML, CSS, and JavaScript. No build step: GitHub Pages serves these files as they are.

## Updating the site

Almost everything that changes during the season lives in **`content.js`**: sponsors, events, season updates, roster, mentors, outreach, and contact info. Instructions are at the top of that file.

To edit it on github.com:

1. Open `content.js` and click the pencil icon.
2. Make your change. Keep the quotes and commas exactly like the lines around it.
3. Choose **"Create a new branch and start a pull request"**, then **Propose changes**, so a team lead can check it before it goes live.

Logos go in `images/sponsors/`, photos in `images/photos/`. Use first names only for students, and remove location data from photos before uploading.

If a page goes blank after an edit, there's almost always a missing comma or quote in `content.js`.
